# 3Vis3 Tap

## How do I install these formulae?

`brew install 3vis3/tap/<formula>`

Or `brew tap 3vis3/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "3vis3/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
